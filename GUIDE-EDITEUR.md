# Guide de l’éditeur — portfolio M.ELQADD’ARTchitects

Ce guide explique comment modifier le portfolio sans toucher au code : ajouter un projet, changer un texte ou remplacer une image.

---

## 1. Se connecter

1. Ouvrir **`https://mouna-portfolio.pages.dev/admin/`** (l’adresse peut changer si un nom de domaine est ajouté).
2. Cliquer sur **Sign in with GitHub** et se connecter avec votre compte GitHub.
3. Deux rubriques s’affichent à gauche :
   - **Projets académiques** : les projets de la page « Projets »
   - **Profil & contact** : la biographie, la formation, les logiciels, les contacts et le CV

---

## 2. Publier une modification

- Chaque **Save** (Enregistrer) **publie** la modification : le site se met à jour tout seul en **1 à 2 minutes**.
- Il n’y a pas de brouillon séparé : ne cliquez sur Save que lorsque le contenu est prêt.
- Si une information est invalide (une image manquante, par exemple), le site **reste sur la version précédente** et rien n’est cassé. Vérifiez la modification ou demandez de l’aide.

---

## 3. Ajouter un projet

**Projets académiques** → **New** (Nouveau), puis remplir :

| Champ | Conseil |
| --- | --- |
| **Identifiant** | L’adresse de la page : minuscules, chiffres et tirets, sans accents. Ex. `bibliotheque-des-berges` donne `/works/bibliotheque-des-berges`. **Ne plus le modifier après publication.** |
| **Numéro** | Affiché sur le site : `001`, `002`… |
| **Ordre d’affichage** | Les plus petits numéros apparaissent en premier. |
| **Afficher sur la page d’accueil** | Le projet apparaît dans « Projets choisis ». |
| **Contenu provisoire** | À **décocher** : sinon le badge « Provisoire » s’affiche. |
| **Titre, sous-titre, textes** | Français et anglais. Si l’anglais est vide, le français s’affiche dans les deux langues (et inversement). |
| **Catégorie / Format** | Choisir dans la liste. |
| **Image de couverture** | Grande image horizontale, en haut de la page du projet. |
| **Vignette** | Optionnelle : image verticale pour les grilles. Si elle est vide, la couverture est utilisée. |
| **Fiche technique** | Lignes libres : Atelier, Encadrant(s), Programme, Surface, Durée… |

Les **sections de texte vides n’apparaissent pas** sur le site. Inutile de tout remplir d’un coup.

---

## 4. Les images du projet

Dans **Images du projet**, cliquez sur **Add** pour chaque image. Le **type d’image** décide de la section où elle s’affiche :

| Type choisi | Section sur le site |
| --- | --- |
| Analyse de site | Analyse de site |
| Croquis, Diagramme | Croquis & diagrammes |
| Dessin technique / détail | Dessins techniques |
| Plan | Plans |
| Coupe, Façade / élévation | Coupes & façades |
| Maquette | Maquettes |
| Visualisation / rendu, Photographie | Visualisations finales |

Conseils :

- **L’ordre de la liste est l’ordre d’affichage.** Les images peuvent être réordonnées dans la liste.
- **Formats acceptés :** JPG, PNG, WebP. Les images sont **converties et allégées automatiquement** à l’envoi : vous pouvez déposer de grands rendus.
- **Les proportions sont respectées :** un plan n’est jamais recadré. Les images très allongées (coupes, façades) prennent toute la largeur.
- **Légende :** courte et technique, ex. « Plan du rez-de-chaussée — 1:200 ».
- **Description de l’image :** une phrase qui dit ce que montre l’image. Elle sert aux personnes malvoyantes et au référencement.
- **Ne publiez que vos propres images**, ou des images dont vous avez les droits.

---

## 5. Profil & contact

**Profil & contact** → **Profil, biographie et contact**. On y modifie :

- la **biographie** (courte pour l’accueil, longue pour « À propos »)
- les **intérêts**, la **formation**, la **démarche**, les **compétences**, les **logiciels** et les **langues**
- l’**image principale** de l’accueil et le **portrait** (optionnel : sans portrait, la page À propos affiche le nom et le statut)
- les **contacts** : e-mail, liens complets LinkedIn / Instagram (commençant par `https://`), ville
- le **CV** en PDF

Un champ de contact vide s’affiche « À compléter » sur le site, jamais comme un lien cassé.

---

## 6. Supprimer ou masquer

- **Masquer de l’accueil :** décocher « Afficher sur la page d’accueil ».
- **Supprimer un projet :** l’ouvrir, puis choisir **Delete** (Supprimer) dans le menu de l’éditeur.

---

## Besoin d’aide ?

Si une publication n’apparaît pas au bout de 5 minutes, le site est resté sur la version précédente : un champ est probablement invalide. Notez ce que vous avez modifié et demandez de l’aide.
